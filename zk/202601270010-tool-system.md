# Tool System Empowers LLMs

The Tool System enables the LLM to perform actions within Neovim or the operating
system, effectively giving it "hands" to edit code, run commands, or search files.

## Workflow

1. **Parsing:** The system scans the LLM's response for specific tool invocation
   patterns (XML-like tags or JSON).
2. **Resolution:** Validates that the requested tool exists and is configured.
3. **Approval:** Checks if the tool requires user permission before execution.
4. **Execution:** Runs the tool's logic (Lua function).
5. **Feedback:** The tool's output (stdout/stderr) is fed back into the chat as a
   new message, allowing the LLM to react to the result.

## Tool Mechanics

- **Detection:** Tools are detected using regex or structural parsing of the LLM output.
- **Orchestration:** The `Orchestrator` manages the queue of tool calls, ensuring
  sequential or parallel execution as appropriate.
- **Edit Tracking:** Modifications to buffers are tracked to provide "diff" views
  or undo capabilities.

## Approval System

Security is managed via an approval layer (`approvals.lua`):
- **Per-Session:** Approvals are cached per chat buffer.
- **Granularity:** Can approve entire tools or specific shell commands.
- **"YOLO" Mode:** An optional mode that bypasses approvals for a fluid, autonomous
  agent experience (use with caution).
